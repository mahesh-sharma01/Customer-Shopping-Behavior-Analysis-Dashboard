# 🛒 Customer Shopping Behavior Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing customer shopping behavior to understand purchasing patterns, customer preferences, and factors influencing buying decisions. The dataset is processed using Python, analyzed using SQL, and visualized through an interactive Power BI dashboard to generate actionable business insights.

The main goal is to help businesses improve customer targeting, increase sales, and optimize marketing strategies using data-driven decisions.

---

## 🎯 Objectives
* Analyze customer demographics and purchasing behavior
* Identify top-selling products and categories
* Study impact of discounts, promotions, and payment methods
* Understand customer segmentation patterns
* Detect seasonal and regional buying trends
* Build an interactive dashboard for business insights

---

## 🛠️ Tools & Technologies Used
* Python (Data Cleaning & EDA)
* Pandas, NumPy (Data Processing)
* Matplotlib, Seaborn (Visualization)
* SQL (Business Queries & Analysis)
* Power BI (Interactive Dashboard)
* Excel (Initial Data Understanding)

---

## 📂 Project Workflow

### 1. Data Collection
* Imported raw customer shopping dataset

### 2. Data Cleaning (Python)
* Removed missing values and duplicates
* Standardized categorical values
* Converted data types for analysis

### 3. SQL Business Analysis
* Revenue analysis by gender and category
* Discount and promo code impact
* Customer segmentation queries
* Payment method analysis
* Frequency of purchase analysis

### 4. Exploratory Data Analysis (EDA)
* Customer age distribution analysis
* Product category performance
* Season-wise shopping trends
* Spending behavior patterns

### 5. Dashboard Development
* Built Power BI dashboard
* Added KPIs:
  * Total Customers
  * Average Purchase Value
  * Total Revenue
* Created visuals for:
  * Category-wise sales
  * Gender analysis
  * Subscription vs non-subscription
  * Seasonal trends

---

## 📊 Key Insights
* Clothing is the most purchased category
* Certain age groups contribute highest revenue
* Discounts significantly influence purchase behavior
* Subscription customers show different buying patterns
* Seasonal trends strongly affect sales performance
* Payment method preference impacts spending behavior

---

## 📈 Dashboard Features
* KPI cards (Revenue, Customers, Average Spend)
* Category-wise revenue breakdown
* Customer segmentation analysis
* Seasonal shopping behavior
* Payment method analysis
* Interactive filters (Gender, Category, Season, Location)
